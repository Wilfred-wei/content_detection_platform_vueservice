# 前端项目 `/M3/` 路径配置修复总结

## 问题描述

由于需要在公网通过 `http://8.130.159.131/M3/` 访问前端应用，设置了 `base: "/M3/"`，导致所有静态资源和 API 请求路径都需要添加 `/M3/` 前缀。

### 2. 工具函数

#### `frontend/src/utils/assetPath.ts` - 新建
```typescript
/**
 * 静态资源路径工具函数
 * 用于处理 Vite base 路径配置下的静态资源引用
 */

// 获取静态资源完整路径
export function getAssetPath(path: string): string {
  const cleanPath = path.startsWith('/') ? path.slice(1) : path
  const basePath = import.meta.env.BASE_URL || '/'
  const normalizedBase = basePath.endsWith('/') ? basePath : `${basePath}/`
  return `${normalizedBase}${cleanPath}`
}

// 获取示例图片路径（支持 URL 编码）
export function getExampleImagePath(category: string, filename: string, encode: boolean = true): string {
  const processedFilename = encode ? encodeURIComponent(filename) : filename
  return getAssetPath(`/examples/${category}/${processedFilename}`)
}

// 获取静态图片路径
export function getStaticImagePath(filename: string): string {
  return getAssetPath(`/static/images/${filename}`)
}

// 获取视频路径
export function getVideoPath(filename: string): string {
  return getAssetPath(`/static/videos/${filename}`)
}
```

// ✅ 新增：修复热力图 URL
const fixHeatmapUrl = (url: string): string => {
  if (!url) return url
  // 处理相对路径
  if (url.startsWith('/ai-heatmap/') || url.startsWith('/heatmap/')) {
    return getAssetPath(url.startsWith('/') ? url : `/${url}`)
  }
  // 处理完整 URL
  if (url.includes('://') && !url.includes('/M3/')) {
    const urlObj = new URL(url)
    if (urlObj.pathname.startsWith('/ai-heatmap/') || urlObj.pathname.startsWith('/heatmap/')) {
      urlObj.pathname = `/M3${urlObj.pathname}`
      return urlObj.toString()
    }
  }
  return url
}

const getProxyPath = (path: string): string => {
  const baseURL = import.meta.env.BASE_URL || '/'
  return `${baseURL}${path.startsWith('/') ? path.slice(1) : path}`
}

// ✅ 改进：normalizeServiceUrl 函数
const normalizeServiceUrl = (url?: string) => {
  if (!url) return url as any
  try {
    // 处理完整 URL
    if (url.startsWith('http://') || url.startsWith('https://')) {
      if (url.includes('localhost:8002') || url.includes('localhost:8003') || url.includes('localhost:8010')) {
        const urlObj = new URL(url)
        // 根据端口判断使用哪个代理前缀
        let proxyBase = '/M3'
        if (url.includes(':8002')) proxyBase += '/ai-detect'
        else if (url.includes(':8010')) proxyBase += '/rumor'
        else if (url.includes(':8003')) proxyBase += '/video-analysis'
        return proxyBase + urlObj.pathname
      }
      return url
    }
    // 处理本地路径
    if (url.startsWith('/')) {
      return getProxyPath(url)
    }
    return url
  } catch (e) {
    console.warn('URL normalize error:', url, e)
    return url
  }
}

## Nginx 配置（公网服务器）

需要在公网服务器 `8.130.159.131` 上配置：

```nginx
server {
    listen 80;
    server_name 8.130.159.131;

    location /M3/ {
        # 去掉 /M3/ 前缀后转发到内网 Vite 服务器
        rewrite ^/M3/(.*)$ /$1 break;
        proxy_pass http://10.69.50.194:25173;

        # WebSocket 支持（HMR 需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_cache_bypass $http_upgrade;

        proxy_redirect off;
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
}
```

## 请求流程说明

### API 请求流程：
```
浏览器: POST http://8.130.159.131/M3/ai-detect/detect
   ↓
Nginx (8.130.159.131:80):
   rewrite: /M3/ai-detect/detect → /ai-detect/detect
   proxy_pass → http://10.69.50.194:25173
   ↓
Vite (10.69.50.194:25173):
   匹配代理规则: /M3/ai-detect
   rewrite: /ai-detect/detect → /detect
   proxy_pass → http://localhost:8002
   ↓
后端 (localhost:8002):
   处理 /detect 请求
   返回结果
```

### 静态资源流程：
```
浏览器: GET http://8.130.159.131/M3/examples/real_img/J16.jpg
   ↓
Nginx (8.130.159.131:80):
   rewrite: /M3/examples/... → /examples/...
   proxy_pass → http://10.69.50.194:25173
   ↓
Vite (10.69.50.194:25173):
   返回 public/examples/real_img/J16.jpg
```

### WebSocket (HMR) 流程：
```
浏览器: ws://8.130.159.131/M3/__vite_hmr
   ↓
Nginx (8.130.159.131:80):
   proxy_pass → http://10.69.50.194:25173

```

## 关键要点总结

### 1. base 路径设置
```typescript
// vite.config.ts
base: "/M3/"

// router/index.ts
history: createWebHistory('/M3/')
```

### 2. Vite 代理配置
所有代理规则必须添加 `/M3` 前缀：
```typescript
'/M3/ai-detect': { ... }
```

### 3. 动态路径处理
使用工具函数统一处理：
```typescript
getAssetPath('/examples/xxx.jpg')  // → /M3/examples/xxx.jpg
getExampleImagePath('rumor', 'x.jpg')  // → /M3/examples/rumor/x.jpg
getProxyPath('/ai-detect/health')  // → /M3/ai-detect/health
```

### 4. 后端返回 URL 处理
后端可能返回多种格式：
- `http://localhost:8002/xxx` → 需要转换为 `/M3/ai-detect/xxx`
- `/ai_image_detection/xxx` → 需要转换为 `/M3/ai_image_detection/xxx`
- `/heatmap/xxx` → 需要转换为 `/M3/ai-heatmap/xxx`

使用 `normalizeServiceUrl` 或 `fixHeatmapUrl` 处理。

### 5. Nginx 配置关键点
```nginx
# 必须去掉 /M3/ 前缀后再转发
rewrite ^/M3/(.*)$ /$1 break;
proxy_pass http://10.69.50.194:25173;

# 必须支持 WebSocket
proxy_http_version 1.1;
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

## 注意事项

1. **重启服务**: 修改 `vite.config.ts` 后必须重启 Vite 开发服务器
2. **Nginx 配置**: 公网服务器的 nginx 配置必须正确，否则会出现 404/502 错误
3. **URL 编码**: 文件名包含特殊字符时需要 URL 编码（如空格、中文等）
4. **大小写敏感**: Linux 文件系统区分大小写，确保文件名大小写正确
5. **HMR 限制**: WebSocket 连接可能不稳定，不影响功能使用，只是热更新可能失效
6. **代理规则顺序**: Vite 代理匹配是按顺序的，更具体的规则要放在前面
